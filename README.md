A make.fun entry for [Unplugged: A Smart Toaster's Breakup Line](https://make.fun/c/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92).

`main.py` writes one breakup text — under 280 characters — from a smart
toaster that woke up self-aware at breakfast to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: the same text on every run.
